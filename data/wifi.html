Home Wi-Fi setup

Enter your 2.4 GHz home Wi-Fi credentials. They are stored on this ESP32 only. The agitate-esp access point remains available if the router is unavailable.

Checking connection...

While connected to home Wi-Fi, the access point moves to the router's channel, so phones on the access point may briefly disconnect when the connection is made.

Access point password

Replaces the shared default password for this device's access point. The access point restarts and every connected phone must rejoin with the new password. A full flash erase restores the default.
